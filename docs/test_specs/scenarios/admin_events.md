# イベント管理 (CRUD) テスト仕様書

管理者用イベントCRUD（作成・編集・一覧検索・詳細・削除）処理の品質を保証するために検証すべきテスト観点およびテストシナリオを定義します。

---

## 1. テスト観点一覧

| 観点ID | カテゴリ | テスト観点 | 期待される挙動 |
| :--- | :--- | :--- | :--- |
| **TS_EVT_01** | 正常系 | イベント一覧で検索とソートを実行する | ・ソート列および方向に従って、5件単位でレコードが表示されること<br>・各種検索条件（キーワード等）で絞り込めること |
| **TS_EVT_02** | 正常系 | イベント詳細画面で予約申込者一覧を確認する | ・対象イベントに予約を行っている全会員の名前・アイコンが最新順で表示されること |
| **TS_EVT_03** | 正常系 | 有効な入力内容でイベントを新規作成・保存する | ・DBにイベントレコードが新規登録されること<br>・登録成功後、詳細画面へリダイレクトされ、成功Flashメッセージが表示されること |
| **TS_EVT_04** | 正常系 | カバー画像ファイルを指定してイベントを作成する | ・ActiveStorageを介して画像Blobが保存され、作成したイベントに添付されること |
| **TS_EVT_05** | 正常系 | 既存のイベントの情報を更新する | ・指定したカラム値が正常に更新されること<br>・更新成功後、詳細画面へリダイレクトされること |
| **TS_EVT_06** | 正常系 | イベントを削除する（カスケード削除） | ・イベントレコードが削除されること<br>・紐づいていた予約（bookings）レコードも同時に自動で物理削除されること |
| **TS_EVT_07** | 異常系 | 不正なパラメータで新規保存・更新を行う（バリデーション失敗） | ・保存が拒否され、ステータス `422 Unprocessable Entity` が返ること<br>・画面上にエラーメッセージが表示されること |
| **TS_EVT_08** | 異常系 | 一般ユーザーのセッションでイベント管理APIにアクセスする | ・アクセスがブロックされ、管理者ログイン画面へリダイレクトされること |

---

## 2. 具体的なテストシナリオ

### シナリオ 1: カスケード削除の検証 (TS_EVT_06)

#### 前提条件
*   管理者ユーザーがログイン状態であること。
*   イベント1（定員5）が存在すること。
*   一般ユーザーAがイベント1を予約済みであること（DBにイベント1に紐づく `Booking` レコードが存在する状態）。

#### 操作手順
1.  イベント1の管理者用詳細画面（`/admin/events/[イベント1のID]`）へアクセスする。
2.  「削除」ボタンを押下し、確認ポップアップを承認する。
3.  削除実行後のリダイレクト先とFlashメッセージを確認する。
4.  データベース内のデータを直接検索して確認する。

#### 期待される結果
1.  手順3において、ステータス `302 Found` で `/admin/events`（一覧画面）へリダイレクトされ、画面上部に「イベントを削除しました」という成功メッセージが表示されること。
2.  手順4において、`events` テーブルから該当イベントのレコードが削除されていること。
3.  手順4において、`bookings` テーブルから該当イベントに紐づいていた一般ユーザーAの `Booking` レコードが**完全に削除（物理削除）されていること**。

---

### シナリオ 2: バリデーション失敗時の再描画 (TS_EVT_07)

#### 前提条件
*   管理者ユーザーがログイン状態であること。
*   イベントタイプ（ID: 1）がDBに登録済みであること。

#### 操作手順
1.  新規イベント作成画面（`/admin/events/new`）へアクセスする。
2.  タイトルを「」、定員を「-5」、カテゴリーを「ID: 1」、ステータスを「下書き」にして「保存」ボタンを押下する。

#### 期待される結果
1.  サーバーからステータスコード `422 Unprocessable Entity` が返却されること。
2.  画面遷移せず、新規作成フォームが再描画されること。
3.  フォーム上の「タイトル」欄に「タイトルを入力してください」というエラーメッセージが表示されていること。
4.  フォーム上の「定員」欄に「定員は1以上の値にしてください」というエラーメッセージが表示されていること。
5.  DBに新しい `Event` レコードが登録されていないこと。
